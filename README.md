# handshake-demo

My AI agent calls an airline's AI agent to change my flight. The airline checks who the agent is, lets it look but not touch, and pings my phone before it spends a dollar. If I don't answer, nothing happens, and there's a signed receipt that proves it.

Built on [PACT](https://openpactprotocol.org/spec), Decagon and Instinct's open protocol for personal agent consent. PACT covers agents talking over HTTP. This shows what it looks like on an actual phone call.

Work in progress. Full writeup, demo video, and how to run it coming soon.
